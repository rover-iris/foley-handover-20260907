# 音效工作流交接包

影视音效（foley）贴轨工作流交接包：成套方法论文档（00~12 号）+ pipeline 脚本与资产表 + 三个 agent skill 快照。覆盖「视频逐秒动作分析 → 音源库检索选材 → REAPER 自动贴轨 → 分轨导出」全链路，与具体剧集无关——方法照搬，路径与项目参数开工时问人。

## 快速开始

1. **装 skill**：`skill快照/` 下三个子目录整体拷到你的 agent 平台 skill 目录（如 `~/.claude/skills/`）
2. **装依赖**：REAPER（开 Distant API）+ `pip install reapy_boost` + ffmpeg（详见 02 号）
3. **配音源库**：本地音源机器用 `scripts/pipeline/asset_library.db`；音源挂 NAS 的机器用 `asset_library_nas.db`（零本地依赖；详见 04 号「新机首次引导」）

入门从 **[`00_从这里开始_README.md`](00_从这里开始_README.md)** 读起，按其阅读顺序依次读完再动手。

## 内容

| 位置 | 内容 |
|---|---|
| `00~09, 12_*.md` | 成套方法论文档（08 是坑速查；12 是详细变更日志） |
| `skill快照/` | reaper-foley-workflow / video-action-analysis / reaper-remote-ops 三个 skill（安装源） |
| `scripts/pipeline/` | 检索引擎（SQLite FTS5 + LLM 同义词扩展）+ 资产表 DB 双版本 |

## 约定

- 检索同义词扩展需自备 DashScope key：环境变量 `DASHSCOPE_API_KEY`（不配则自动降级为原词检索，功能不中断）
- NAS 音效资源绝对只读；`资源库\_索引\` 为批准的索引产物写入区
